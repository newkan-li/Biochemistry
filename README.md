# 生物化学 · 本地自学网页

朱圣庚《生物化学》第4版 · bc01–14 教师课件逐页详解。

## 推荐入口

- **bc01–14 自学主页**：`bc.html`
- 36章详细目录：`learn.html`
- 教材对照与学习时间：`textbook.html`

## 学习顺序

bc01 → bc02–05（蛋白质）→ bc06–08（酶）→ bc09（糖）→ bc10（脂质与膜）→ bc11–12（核酸）→ bc13（维生素与辅酶）→ bc14（激素与信号转导）。

每章建议：先做诊断测，再学 AI主讲/原书精读，最后做章节测试并进入错题复习。

## 本地运行

```bash
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000/bc.html`。

学习记录（已读、作答、错题、手写）保存在本机浏览器 localStorage，不会上传。换设备或清理浏览器前，请用页面内的数据备份功能导出。
